# Graphite 공학용 계산기 (Android)

그레이 톤의 차분한 UI를 가진 오프라인 공학용 계산기입니다.
설치 파일: [`release/Graphite-Calculator-1.0.apk`](release/Graphite-Calculator-1.0.apk) (Android 8.0 이상)

## 기능
| 화면 | 내용 |
| --- | --- |
| 계산 | 수식 입력·커서 편집, 실시간 미리보기, 2nd/hyp, DEG/RAD/GRAD, 복소수(i, ∠ 극형식), 메모리(M±), 변수 A–D·X·Y (STO/RCL), Ans, 분수/대분수/DMS 전환, π·√·분수 정확값 힌트, 함수 팔레트(70여 개 함수, ∫·d/dx·Σ·Π 포함) |
| 그래프 | y=f(x), r=f(θ) 극좌표, (x(t), y(t)) 매개변수 4개 동시, 팬·핀치 줌, 탭 추적, 근·극값·교점·y절편·정적분, 값 표 |
| 방정식 | 10차까지 다항식(복소근), 6원 연립 일차, 일반 방정식 f(x)=g(x)의 모든 실근 |
| 미적분 | 1~4차 도함수·접선, 무한 구간 정적분(G7/K15), 좌/우 극한, 무한 급수 Σ·Π, 테일러 전개 |
| 행렬 | 6×6까지 덧셈·곱셈·행렬식·역행렬·전치·거듭제곱·계수·대각합·RREF·특성다항식·고유값/고유벡터 |
| 벡터 | 2D/3D 내적·외적·크기·사잇각·투영·단위벡터 |
| 통계 | 1변수 요약통계 20여 항목 + 히스토그램, 2변수 회귀 5종(선형/2차/지수/거듭제곱/로그) + 산점도·예측 |
| 확률분포 | 정규·t·χ²·지수·이항·포아송: 확률밀도, 누적확률, 구간확률, 역함수, 그래프 |
| 진법 | HEX/DEC/OCT/BIN, 8~64비트, 부호/무부호, AND·OR·XOR·NOT·NAND·NOR·시프트·회전, 비트 토글 |
| 단위 | 16개 분야(길이·넓이·부피·질량·온도·압력·에너지·데이터·연비 등, 평·근·자 포함) |
| 상수 | CODATA 2018 물리 상수 50여 개, 탭하면 계산기에 입력 |
| 공학 | 옴의 법칙, 저항 색띠(4/5/6띠) + E12/E24/E96 표준값, 직렬·병렬 합성, 전압 분배기, RLC 공진·Q·임피던스, 데시벨, 삼각형 풀이, 소인수분해·약수·φ(n)·GCD/LCM |
| 기록·설정 | 계산 기록 300개 저장, 다크/라이트 테마, 표시 형식(NORM/FIX/SCI/ENG), 천 단위 구분, 진동 |

## 빌드
```
# Android SDK(platform 35, build-tools 35) 필요
echo "sdk.dir=/path/to/android-sdk" > local.properties
./gradlew assembleRelease
# 결과: app/build/outputs/apk/release/app-release.apk
```
UI는 `app/src/main/assets/www`의 HTML/CSS/JS로 되어 있으며 WebView에서 동작합니다. 릴리스 빌드는 개인 설치용으로 디버그 키로 서명됩니다.
